# grilling — grill-me の本体

隣の `grill-me` スキルの本体（実際の動きが書いてあるファイル）です。
普段ユーザーが直接呼ぶのは `/grill-me` のほうで、こちらは裏で動きます。
**2つでひと組**なので、必ず `grill-me` とセットで取り込んでください。

## 中身の仕組み（かんたんに）

- あなたの計画を「決めごとのツリー（枝分かれ図）」として整理します
- 「今すでに決められること」から順に質問を組み立てて、1問ずつ聞いてきます
- 答えるたびに次に聞ける質問が増えていき、聞くことがなくなったら完了です

## この版の調整内容

- 質問は1問ずつ出題（元の版は複数質問を一括出題）。回答を待ってから次に進みます
- 会話はユーザーの言語で行います（日本語で話せば日本語で返ります）
