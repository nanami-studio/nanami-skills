# grill-me — 質問攻めで計画を鍛えるスキル（入り口）

「グリルして」と頼むと、Claudeが逆にあなたへ質問してくるスキルです。
1問ずつ答えていくうちに、企画や決めごとの抜け漏れがなくなっていきます。

このスキルは「入り口」で、本体は隣の `grilling` フォルダです。
**2つでひと組**なので、片方だけ入れても動きません。必ずセットで取り込んでください。

## 入れ方（コピペで使えます）

Claude Code（クロードコード）に、次の文をそのまま貼り付けてください。

```
github.com/nanami-studio/nanami-skills の skills/grill-me と grilling を
私のパソコンのスキルとして使えるように入れて
```

## 使い方の例

```
/grill-me 来月から始めようと思っていることを決めたい
```

あとはClaudeの質問に1つずつ答えていくだけです。

## この版の特徴

- 質問は1問ずつ（元の版は複数質問を一括出題）。「まとめて聞いて」と言えば一括にもできます
- 日本語で話しかければ日本語で返ってきます
