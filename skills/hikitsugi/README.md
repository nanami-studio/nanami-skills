# hikitsugi — 会話の「セーブポイント」を作るスキル

セッション（Claudeとの1回の会話）の区切りに「引き継ぎして」と頼むと、
進行中の作業をメモに保存してくれるスキルです。
新しいセッションで「前回の続き」と言うだけで、そのまま作業を再開できます。
ゲームのセーブポイントのように、会話の続きを次回にそのまま引き継げます。

## 入れ方（コピペで使えます）

Claude Code（クロードコード）に、次の文をそのまま貼り付けてください。

```
github.com/nanami-studio/nanami-skills の skills/hikitsugi を
私のパソコンのスキルとして使えるように入れて
```

## 使い方

1. セッションの終わりに「引き継ぎして」と頼む
2. Claudeが作業メモを保存し、「次の声のかけ方」を教えてくれる
3. 新しいセッションを開いて「前回の続き」と言えば再開
