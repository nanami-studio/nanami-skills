# まとめスキル（/matome）

ユーザーは会話中に思いついたことを順不同で話す。それを後から拾い集めて、
**そのままコピペして次の相手（Claude・ChatGPT・サブエージェント）に投げられる文章**にするのがこのスキルの役割。

- 作るのは「プロンプト（指示書）」であって、記憶ファイルの更新ではない
- ファイルには保存しない。チャットにコードブロックで出すだけ

## 手順（この順番で）

### 1. ユーザーの発言を拾う

- 今のセッションの会話を最初までさかのぼる
- 拾うのは「やりたいこと・気になっていること・頼みごと」
- **Claude側の提案ではなく、ユーザー本人が言ったことを優先する**
  - Claudeが提案してユーザーが「いいね」と言ったものは拾ってよい
  - Claudeが提案しただけで反応がなかったものは拾わない
- 途中でやめたこと・却下したことは拾わない

### 2. やること別に分類する

見出しは以下の4つで固定。**該当するものがない見出しは出さない**。

- `## 🔥 今すぐやる`
- `## 📌 あとでやる`
- `## 💡 アイデア・検討中`
- `## ❓ 未確定（ユーザーに確認が必要）`

迷ったら「今すぐやる」に入れず、`❓ 未確定` に置いてユーザーに聞く。

### 3. 出力先を必ず最初に聞く（AskUserQuestion・3択）

まとめを書き始める前に、AskUserQuestion で**必ず**この3つから選んでもらう。
選ばれた先によって文章の書き方が変わるので、勝手に決めない。

**A. Claudeの新しいセッション用**
- 前提の説明は軽めでよい（記憶ファイルを読めば分かるため）
- 関連する記憶ファイルのフルパスを添える
  （`~/.claude/projects/<プロジェクト>/memory/〇〇.md`）
- 決まった合図があれば添える（例：「〇〇プロジェクトの続き」「△△の件の続き」）

**B. ChatGPT・Codexなど外部AI用**
- こちらの事情を**一切知らない相手**向けに、背景・前提・制約を丁寧に書く
- ⚠️ 社内ルール（必ず守る）：次のものは入れない
  - 個人情報（氏名・住所・電話・メールアドレス）
  - 取引先の名前・屋号
  - 料金の実額
  - APIキー・パスワード・トークン
- 入りそうな場合は伏せ字にして、その行に `※伏せた` と明記する
  （例：`- [ ] A社（※伏せた）のトップページを直す`）

**C. サブエージェントへの作業指示書用**
- 担当部署を明記する：🛠エンジニア／🔍リサーチャー／🎨デザイナー／✍️ライター／💰経理・事務／📣SNS・マーケ／✅校正・チェック
- 次の3つを必ず書く
  - ゴール（何ができたら終わりか）
  - 成果物（何を出すか）
  - 触ってよいファイル（フルパス。触ってほしくないものがあればそれも明記）

### 4. コードブロックで出す

出力は ```markdown で囲んでチャットに出す。そのままコピーできる形にする。
ファイルには保存しない。

### 5. 出したあとに一言で聞く

「これでいい？足りないものある？」と短く聞き、追加・削除・分類の変更にその場で応じる。
修正したら、また全文をコードブロックで出し直す（差分だけ出さない）。

## 書き方ルール

- チェックボックス形式（`- [ ] 〜`）で書く
- 1項目1行。長くなるなら子行でぶら下げる

```markdown
- [ ] トップページの写真を差し替える
  - 使う写真：〇〇フォルダの3枚
```

- **ユーザーが言っていないことをClaudeが勝手に足さない**
- 推測で補った箇所は `（※推測）` と明記する
- 専門用語・英語は避けて平易な日本語で書く（ユーザーの CLAUDE.md に書き方のルールがあればそれに従う）
- 日付を書くときは**セッション冒頭の「現在日時」を使う**。推測で書かない
- 「明日」「来週」などの相対日付は、その現在日時をもとに絶対日付（2026-09-15 など）に直す

## 出力の見本

```markdown
# やりたいことまとめ（2026-09-15）

## 🔥 今すぐやる
- [ ] トップページのスマホ表示の崩れを直す
  - 375px幅で横スクロールが出ている

## 📌 あとでやる
- [ ] お知らせページに1本記事を足す

## 💡 アイデア・検討中
- [ ] 問い合わせボタンをもう少し目立たせたい（※推測：「押しにくい」という話からの解釈）

## ❓ 未確定（ユーザーに確認が必要）
- [ ] 料金ページを直すかどうか（「気になる」とだけ言っていた）
```

## 注意

- この作業はメインの会話が自分でやる。サブエージェントには投げない（会話全体を知っているのはメインの会話だけ）
- セッションを終える準備を頼まれているなら、このスキルではなく /hikitsugi を使う
- 記憶ファイルの更新はこのスキルではやらない。必要そうなら最後に一言だけ提案する
