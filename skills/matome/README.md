# matome — やりたいことをプロンプトにまとめるスキル

会話の中でバラバラに話した「やりたいこと」を拾い集めて、
そのままコピペできる指示書（プロンプト）に変換してくれるスキルです。
思いついた順に話しただけの内容が、チェックリスト形式のマークダウンになって出てきます。

## 入れ方（コピペで使えます）

Claude Code（クロードコード）に、次の文をそのまま貼り付けてください。

```
github.com/nanami-studio/nanami-skills の skills/matome を
私のパソコンのスキルとして使えるように入れて
```

## 使い方

1. ひととおり話し終わったら「まとめて」「プロンプトにまとめて」と頼む
2. 「誰に渡すか」を3つから選ぶ（Claudeの新しいセッション／ChatGPTなど外部のAI／サブエージェント）
3. 渡す相手に合わせた指示書がコードブロックで出てくるので、そのままコピーして使う

出てくる指示書は、内容ごとに次の4つに仕分けされます（あてはまるものがない見出しは出ません）。

- 🔥 今すぐやる
- 📌 あとでやる
- 💡 アイデア・検討中
- ❓ 未確定（ユーザーに確認が必要）

## 気をつけていること

- あなたが言っていないことを勝手に足しません。補ったところには `（※推測）` と書きます
- 迷ったものは「今すぐやる」に入れず「未確定」に置いて、あとから確認します
- 外部のAIに渡すときは、個人情報・取引先の名前・料金の実額・APIキーなどを入れません
- ファイルには保存しません。チャットにコードブロックで出すだけです

## 似ているスキルとの違い

- セッションを終える準備（作業メモの保存・引き継ぎ）は `skills/hikitsugi` のほうです
- こちらは「次に投げる文章を作る」ためのスキルです
